# ФотоСкан — лабораторная работа «Распознавание изображений»

Самостоятельное Android-приложение. Пользователь выбирает фотографию через системный файловый диалог, приложение запускает предобученную модель на телефоне и показывает, что изображено на снимке.

## Что реализовано
- Выбор изображения через ACTION_OPEN_DOCUMENT без запроса доступа ко всей галерее.
- Предпросмотр, повторное распознавание и очистка фотографии.
- Предобученная ML Kit Image Labeling, модель включена в APK.
- Пять наиболее уверенных категорий и их оценки; порог вывода 35%.
- Перевод распространённых категорий на русский; для остальных сохраняется исходная метка модели. Под переводом показана оригинальная английская метка.
- Состояния загрузки, анализа, ошибки чтения и отсутствия уверенного ответа.
- Уменьшение до 1280 пикселей по длинной стороне, коррекция EXIF-ориентации и зеркальности, белый фон для прозрачных изображений.
- Анализ и подготовка изображения не блокируют главный поток.
- Последний снимок сохраняется внутри приложения и повторно анализируется после перезапуска. «Очистить» удаляет эту копию.
- Самостоятельный applicationId ru.photolens.app: приложение устанавливается отдельно от VitaTrack.

## Установка и демонстрация
1. Передайте файл PhotoLens-1.0.apk на Android-телефон с Android 8.0 или выше либо перетащите APK на экран запущенного эмулятора.
2. Откройте «ФотоСкан» → «Выбрать фотографию».
3. Выберите чёткий снимок животного, автомобиля, еды, растения или другой обычной сцены.
4. Дождитесь результата. На экране появятся наиболее вероятная категория, другие метки, оценки и время анализа.
5. Для демонстрации локальной работы заранее сохраните снимок на устройстве, отключите интернет и повторите распознавание.

В ZIP с исходниками нет самого установочного APK — он поставляется отдельно. После установки разрешение на уведомления и камера не нужны.

## Запуск проекта в Android Studio
1. Распакуйте PhotoLens-AndroidStudio.zip.
2. Выберите Open → папку PhotoLens, содержащую settings.gradle. Не копируйте файлы в новый проект.
3. Выберите Gradle JDK 17. Установите SDK Platform 35 и Build Tools через SDK Manager, если IDE предложит.
4. Дождитесь Gradle Sync; первая сборка требует интернета для зависимостей.
5. Выберите телефон или эмулятор и нажмите Run.

Стек: Java 17, Android Gradle Plugin 8.7.3, Gradle Wrapper 8.9, compileSdk/targetSdk 35, minSdk 26.
Зависимости приложения: com.google.mlkit:image-labeling:17.0.9 (bundled) и androidx.exifinterface:exifinterface:1.4.2.

Если Gradle не скачивается из-за Connection refused, это проблема доступа к серверу. Готовый APK не требует сборки. Для ручной настройки Gradle можно скачать официальный gradle-8.9-bin.zip, поместить в C:/Gradle и указать в gradle/wrapper/gradle-wrapper.properties:
```properties
distributionUrl=file:///C:/Gradle/gradle-8.9-bin.zip
```
Остальным зависимостям всё ещё нужен интернет.

## Принцип работы для защиты лабораторной
Здесь используется готовая обученная нейросеть; обучение с нуля не проводится.

1. Пользователь выбирает URI фотографии.
2. PhotoLoader декодирует снимок, уменьшает его и приводит к правильной ориентации/RGB.
3. MainActivity создаёт InputImage и вызывает ImageLabeler.process().
4. Встроенная модель выполняет inference на процессоре устройства.
5. Модель возвращает метки категорий и confidence scores.
6. Labels отбрасывает некорректные/неуверенные ответы, сортирует оставшиеся и выбирает первые пять.
7. Интерфейс отображает результат и время обработки.

Основные файлы:
- MainActivity.java — интерфейс, системный выбор файла, асинхронная загрузка и вызов реальной модели.
- PhotoLoader.java — декодирование, EXIF, уменьшение и подготовка RGB.
- Labels.java — сортировка ответов, фильтр уверенности и локальный словарь.
- PhotoMath.java — расчёт размеров и коэффициента выборки.

Это многометочная классификация всего снимка. Одно фото может получить несколько совместимых меток: например, животное и элемент окружающей среды. Приложение не рисует рамки вокруг объектов и не определяет личность человека по лицу. Высокая оценка не гарантирует правильность; неизвестные модели объекты могут распознаваться ошибочно. Значения оценок показываются из реального ответа модели, не генерируются приложением.

Модель поддерживает более 400 категорий, но не любые предметы мира. Отдельного «обучения» на выбранном пользователем фото нет.

## Приватность
Фото анализируется на устройстве. Разрешение INTERNET удалено из итогового манифеста, поэтому приложение не может отправлять снимки на сервер. Внешние API, ключи и аккаунт не нужны. Модель поставляется внутри APK. Внутренняя копия снимка удаляется кнопкой «Очистить» либо при удалении приложения; резервное копирование отключено. Системный провайдер галереи может отдельно требовать интернет, если выбранное фото ещё находится в облаке.

## Проверки
```powershell
.\test-core.ps1
.\test-android.ps1
.\gradlew.bat assembleDebug lintDebug
```

test-core.ps1 требует JDK 17. test-android.ps1 запускает необязательные тесты Robolectric в моделируемом Android 13; первый запуск скачивает тестовые зависимости. Они не включаются в приложение. Тесты декодера и системного выбора изображения не заменяют проверку реальной нейросети на телефоне.
